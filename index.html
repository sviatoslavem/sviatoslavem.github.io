Cluster Cartography Guide

Cluster Cartography is an advanced tool for visualizing and analyzing the spatial distribution of galaxies within clusters. It facilitates various research methods, including examining galaxy concentrations, identifying filamentary structures, and observing peculiar features. The program also enables the estimation of the proportion of disk and elliptical galaxies in a cluster and analyzes the tendency of galaxies to align with their nearest neighbors.

Main Functions:

1. Data Uploading:

  • Choose a File: Select a file in “.txt” format.
  • Load Data: Click "Load Data" to import data from the chosen file.
  • File Format: The file should include:
    • X, Y: Coordinates of the galaxy in arcseconds.
    • m': Adapted stellar magnitude, used to size the corresponding symbol.
    • E: Ellipticity of the galaxy image, approximated by the best-fitting ellipse.
    • PA: Position angle of the major axis of the ellipse, measured counterclockwise from north.
    • BG: A column for assigning values from 1 to 9 for the brightest galaxies (0 by default in input files). If the source catalog lacks formation data, both E and RA should be set to 0.

Sample Data: Click "Sample DB" to access a sample dataset.

2. Data Visualization:

After loading, the table on the left displays X, Y coordinates, adapted magnitude (m'), ellipticity (E), position angle (PA), and BG (default 0).

3. Map Creation and Saving:

  • Create Map: Generates a cluster map, with each symbol’s size and orientation matching the input data. The map dimensions are 4000×4000 arcseconds.
  • Save Map: Saves the map using the cluster name, based on the input file.
  • Save Histogram: Click to save histograms.

4. Setting Cluster Parameters:

The cluster radius is calculated automatically but can be manually adjusted. Default center coordinates (X, Y) are (0, 0) and can be customized.

Key Analysis Modes:

C-I-O Analysis:

Evaluates galaxy concentration toward the cluster center. The Width parameter determines the size of analysis zones as a fraction of the cluster radius. Calculates the weighted density of galaxies in each zone.

Line Analysis:

Detects linear filamentary substructures in the cluster. Parameters include center coordinates, number of strips along the diameter, and rotation angle.

LHB (LightHouseBeam):

Identifies specific substructures like crosses and half-crosses. The beam rotates in 1° increments, and density variations are displayed as linear or pie charts.

Ellipticity Analysis (E):

Creates a histogram of galaxy distribution based on ellipticity. Facilitates the division of clusters into E-rich and D-rich populations.

Orientation Analysis:

Compares galaxy alignments with their nearest neighbors. Galaxies are highlighted if the direction difference is below a specified Angle Difference.

Binggeli Effect:

Assesses alignment of galaxies with their nearest neighbors or perpendicularly. Filters for E and m' can be used.
